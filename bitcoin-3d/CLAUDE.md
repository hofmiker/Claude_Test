# Bitcoin Chart — 3D Candlestick-Visualisierung

## Live-URL
https://hofmiker.github.io/Claude_Test/bitcoin-3d/

## Dateien
- `index.html` — 3D Candlestick Chart

## Tech-Stack
- Three.js via CDN
- Binance API (Fallback: CoinGecko) für Live-Daten
- Touch: 1-Finger Pan, Pinch-Zoom

## Thumbnail
`screenshots/bitcoin-3d.png` ist eine generische, frei gerenderte 3D-Kerze
(kein echter Screenshot aus der App) — sowohl das Three.js-CDN als auch die
Binance/CoinGecko-APIs sind in der Sandbox-Umgebung per Netzwerk-Policy
blockiert, ein echter Screenshot mit echten Kursdaten war dort nicht möglich.
